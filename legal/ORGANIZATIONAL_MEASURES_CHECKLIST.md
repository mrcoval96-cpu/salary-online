# Организационные меры по персональным данным — чек-лист KORVEX

Этот документ нужен для фиксации мер, которые не могут быть доказаны одним только исходным кодом. Для production каждый пункт должен иметь владельца, дату утверждения и ссылку на evidence.

## Обязательный комплект перед production

- [ ] Утверждена Политика обработки персональных данных.
- [ ] Утверждён текст отдельного согласия на обработку ПД.
- [ ] Утверждено Пользовательское соглашение/оферта под фактическую коммерческую модель.
- [ ] Утверждён DPA/поручение на обработку ПД с организациями-клиентами.
- [ ] Зафиксированы цели обработки, категории субъектов, категории данных и правовые основания.
- [ ] Утверждена retention matrix и порядок legal hold.
- [ ] Утверждён порядок уничтожения/блокирования и форма evidence/акта.
- [ ] Утверждён порядок исполнения запросов субъектов и идентификации заявителя.
- [ ] Утверждён incident response runbook 24/72 и назначены контакты.
- [ ] Проведён реестр subprocessors/integrations, включая SMTP, hosting, storage, monitoring и support.
- [ ] Проверена необходимость/порядок трансграничной передачи; по умолчанию она не включается.
- [ ] Зафиксированы правила допуска сотрудников/подрядчиков к production ПД и прекращения доступа.
- [ ] Проведено обучение лиц, допущенных к ПД, и зафиксировано ознакомление с требованиями конфиденциальности.
- [ ] Утверждены модель угроз, применимый уровень защищённости ИСПДн и набор мер.
- [ ] Проведены приёмочные/security испытания; high/critical риски закрыты либо формально приняты.
- [ ] Проверены backup/restore и защита deletion tombstones при аварийном восстановлении.
- [ ] Собраны подтверждения размещения DB/storage/logs/backups в РФ.
- [ ] Уведомление Роскомнадзора подано/актуализировано и соответствует реальной архитектуре.
